1) What is the difference between var, let, and const?
   => Var is function scoped and it can be updated or redeclared. Let and Const both are block scoped .Let can be updated but not redeclared. On the other hand Const can not be updated or redeclared.
   
2) What is the difference between map(), forEach(), and filter()?
  =>Map function goes through each element in an array and returns something and with the result makes a new array and the original array remains unchanged.
    ForEach function goes through each elementof an array and does a task, it does not create a new array.
   Filter function goes through each element of an array and makes a new array with only the elements that meet a certain condition.

4) How does destructuring assignment work in ES6?
 =>Destructuring in ES6 is a shortcut way to extract values from an array or object and keep the value in a variable.

5 ) Explain template literals in ES6. How are they different from string concatenation?
=> template literals in ES6 is a new way of writing strings where we use back ticks instead of quotes.
In  template literals we can use variable,multiple line text,expression ,function calls in a line but we can not do the same in string concatenation.We have to use + for joining string and variables also we cannot call function directly inside quotes.
